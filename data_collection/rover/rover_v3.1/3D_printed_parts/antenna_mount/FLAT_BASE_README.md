# Flat base for the Rover 3.1 antenna-array mount

`array_mount_flat_base_ezlok_m3.stl` is a production-resolution export of the
simple 112 x 112 x 4 mm plate defined in
[`array_mount_flat_base.scad`](../../../../3D_printing_design_files/array_mount_flat_base.scad).

It has the production antenna mount's exact four-hole pattern and copies the
4.40 mm straight-through E-Z LOK insert fit from the supplied Rover 3.1
top-front STL. See the
[`dimensional notes`](../../../../3D_printing_design_files/array_mount_flat_base.md)
before changing printer, material, or insert type.
