## Top 3 fixes for the PDF

1. **§5 / §9 / Appendix B sign convention (highest priority).** The tutorial's Δφ = ∠b₁ − ∠b₀ and
   φ = ∠(z₁z₀*) are the opposite of `get_phase_diff` (`rf.py:745-746` = ∠z₀ − ∠z₁). Suggested
   wording after the §5 equation: *"NB: the implementation computes the opposite difference,
   ∠b₀ − ∠b₁ = −φ (`get_phase_diff` subtracts channel 1 from channel 0); the ground-truth
   target (`get_ground_truth_phis`) carries a matching −sin θ, so the two minus signs cancel
   end-to-end."*
2. **Appendix B step 4 power definition.** Replace P(θᵢ)=|y|² with P(θᵢ)=|y| and the closed form
   with √2·|z₀|·√(1+cos(φ−φ(θᵢ))), or append: *"the code (`beamformer_given_steering_nomean`)
   returns |y|, not |y|²; the argmax — where φ appears — is identical."* This also reconciles
   Appendix B with §6, which correctly uses magnitude.
3. **§1 / §8 d/λ range.** "≈0.12–0.48 (<0.5)" is contradicted by shipped empirical distributions
   (up to d/λ≈0.99) and by the cited 35 mm array at 5.766 GHz (d/λ≈0.67). Suggested wording:
   *"d/λ ≈ 0.12–0.48 for the 2.4 GHz configurations; 5.8 GHz captures with the same 35 mm
   spacing reach d/λ ≈ 0.67 (and some datasets ≈0.99), where the φ↦θ inversion aliases and
   the learned empirical distribution absorbs the ambiguity."*

Honorable mention: §6's conjugate star (P=|a*x|) — the code applies the steering vector
**without** conjugation (`rf.py:1233`, `:1266`); drop the star or redefine a(θ) with e^{+j}.
